# Serendi · 리서치와 발상

제공된 브랜드 자료, 킥오프 회의 기록, Figma 관찰, 레퍼런스를 읽으며 발상을 쌓는 웹페이지입니다.

**사이트:** https://manypeoplepark.github.io/serendi-research-workspace/

- 통합 리서치 페이퍼 / 16개 사례 라이브러리 / 개인 발상 노트
- 클라이언트 원문 14쪽 전체: 원문 문구·순서·이미지 보존, 헤딩·굵은 강조·구분선, 전체 접기·펼치기, PDF 원본 미리보기·다운로드
- 본문 선택 → 노랑·라벤더·파랑 하이라이트, 색상 변경·삭제·목록
- 선택한 문장을 인용해 메모 남기기, 노트에서 인용 본문으로 돌아가기
- 문장 메모의 점선 밑줄·개수 배지, 표시 클릭으로 메모 보기·수정, 섹션/사례별 메모 개수
- 최근 메모 클릭 → 해당 본문으로 부드럽게 이동·강조, 오른쪽 메모 미리보기와 별도 수정 버튼
- Wanted Sans 웹폰트 적용, 자유 메모 행간 1.6 및 메모 본문 행간 1.65
- 검색, 북마크, 출처 연결 메모, 자유 메모
- JSON 백업·불러오기, Markdown 내보내기, A4 인쇄

개인 노트·북마크·하이라이트는 사용 중인 브라우저에 저장됩니다. 서버 업로드나 다른 방문자와의 자동 공유는 하지 않습니다. 로컬 파일과 사이트 사이, 또는 다른 기기로 옮길 때는 JSON 백업을 사용하세요.

추가 빌드나 라이브러리 없이 `index.html`을 실행할 수 있습니다. `main` 브랜치 루트에서 GitHub Pages로 게시합니다. 레퍼런스 이미지는 HTML 안에 포함되어 있습니다. Wanted Sans 웹폰트는 `assets/fonts/wanted-sans/`에서 함께 제공합니다. 다운로드해 로컬에서 사용할 때도 해당 폴더를 유지하세요.
